# ART OF PLAY: Word as a Playable System

[Leer en español](README.md) · **Play it online: https://soupmeme.github.io/art-of-play-unidad7/**

Student concept for Simulación, Unidad 7 (Universidad Pontificia Bolivariana). **Student concept, not affiliated with Art of Play.**

A homepage hero set on a magic stage. The letters of ART OF PLAY are die-cut letter-cards, dealt into a hand in a random order with a decoy or two. Hold a card with the mouse, flick it at the backdrop, and find out what each one does.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL (desktop browser, mouse). Other commands:

```bash
npm test
```

Runs the 135 tests, including headless physics scenarios with real Rapier; they write the reports in `docs/reports/`.

```bash
npm run build
```

Builds the static site into `dist/`.

```bash
npm run build:font
```

Regenerates the committed typeface JSON from Cinzel (only needed if the glyph set changes).

## Controls

Press on a card to hold it, move to carry and aim, release with a flick to throw. That is all: no keys, no buttons.

## URL switches (not for visitors)

- `?dev`: tuning panel, state readout, collider and word overlays, scripted tools in the console (`aop.flick`, `aop.smoke`), screenshot button.
- `?log`: an opt-in playtest log of when key events first happen, kept only in this browser's local storage, never sent anywhere. Read it back with `?dev` and "copy last playtest log".

## Code

`src/physics` (Rapier world, room, forces, collision groups), `src/letters` (letterforms, families, effects, decoys, the hand), `src/words` (the word function), `src/wall` (bricks, decay), `src/staging` (opening, finale), `src/render` (meshes, textures, stage, lighting), `src/input` (hold and throw), `src/dev` (tools), `src/game.js` (the step), `src/config.js` (every tunable value).
